# 内容审核政策

## 审核标准

平台对所有上传的视频内容进行审核，确保内容符合社区规范。

### 禁止内容

以下内容严格禁止：
- 暴力血腥内容
- 色情低俗内容
- 政治敏感内容
- 虚假信息
- 违法犯罪内容
- 侵犯他人隐私
- 危害未成年人

### 审核流程

1. **机器审核**：AI自动识别问题内容
2. **人工复核**：疑似问题由人工审核
3. **最终判定**：综合评估后决定是否通过

### 违规处理

| 违规等级 | 处理措施 |
|----------|----------|
| 轻微 | 限流/警告 |
| 一般 | 删除内容/功能限制 |
| 严重 | 封禁账号 |
| 违法 | 移交相关部门 |

### 用户反馈

如发现违规内容，可通过举报功能反馈，平台将及时处理。
