# 热门视频计算规则

## 热度算法说明

热门视频的热度由多个因素综合计算得出：

### 基础权重

| 指标 | 权重 | 说明 |
|------|------|------|
| 播放量 | 1.0 | 视频被播放的次数 |
| 点赞数 | 3.0 | 用户点赞的数量 |
| 评论数 | 5.0 | 用户评论的数量 |
| 转发数 | 8.0 | 用户转发的数量 |

### 时间衰减

视频热度随时间衰减，发布时间越近的视频热度衰减越慢：
- 24小时内：热度 = 基础热度 * 1.0
- 48小时内：热度 = 基础热度 * 0.8
- 7天内：热度 = 基础热度 * 0.5
- 7天外：热度 = 基础热度 * 0.2

### 质量分

平台会对视频内容质量进行评估，调整最终热度：
- 优质内容：*1.2
- 普通内容：*1.0
- 低质内容：*0.5

### 最终计算公式

```
热度分 = (播放量 * 1.0 + 点赞 * 3.0 + 评论 * 5.0 + 转发 * 8.0) * 时间衰减 * 质量分
```
