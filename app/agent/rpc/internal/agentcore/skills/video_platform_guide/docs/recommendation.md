# 推荐算法说明

## 个性化推荐策略

系统根据用户行为和偏好，为用户提供个性化的视频推荐。

### 推荐的考量因素

1. **用户行为数据**
   - 历史观看记录
   - 点赞、评论、分享行为
   - 关注的主播
   - 搜索历史

2. **内容特征**
   - 视频分类标签
   - 视频描述关键词
   - 上传者信息
   - 视频质量评估

3. **实时反馈**
   - 当前热门话题
   - 近期热点事件
   - 季节性内容

### 推荐策略

- **冷启动**：新用户主要推荐热门视频
- **兴趣探索**：定期推送不同类型内容，探索用户兴趣
- **多样性**：避免内容过于单一，保持推荐多样性
- **时效性**：优先推荐近期发布的热门内容

### 排序规则

推荐列表按照以下规则排序：
1. 用户兴趣匹配度
2. 视频质量分
3. 热度分
4. 时效性

综合得分最高的视频排在最前面。
